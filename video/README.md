# 动效脚本（scene.html）

一个自包含的 HTML 动画，84 秒，六幕 + 结尾。**同一个时间点永远画出同一帧**，重录、补录、剪掉某一段都不会错位。

## 它是什么

**不是重画的示意图，是直接驱动 `output/figure.svg` 本体。** 图里的每个热图格、每条弦、每根柱、
每个标签都在 SVG 里带独立 id（`cell-*` / `chord-*` / `bar-*` / `clab-*` …），动画按时间轴把它们的
opacity 从 0 推到 1。所以颜色、字体、字号、排版、注解都与成品图完全一致——最后停在的就是那张图。

| 时间 | 幕 | 画面 |
|---|---|---|
| 0–6.5s | 一 | 原始 KO 丰度表铺满屏幕（canvas 绘制，表现"数据"） |
| 6.5–15s | 二 | 一个 KO 的 LA1 / LB1 / LC1 三个值，以及它所属的功能类 |
| 15–26s | 三 | 热图环的 144 个格子按 KO 顺序亮起 |
| 24–33s | 四 | 48 个 KO 编号依次出现 |
| 29–42s | 五 | 17 个功能类轨道与 51 根柱子生成 |
| 35–52s | 六 | 92 条弦依次连上 |
| 45–61s | 七 | 功能类名称、标题、色标、连接度标尺、图例依次出现 |
| 62–80s | 八 | 标题打字机 + 三组说明，停在这张图上 |

## 打开


双击 `scene.html`，或在浏览器里打开 `file://` 路径。数据已内嵌，不需要联网、不需要装任何依赖。

## 录制

1. 打开后按 `H` 隐藏底部控制条，按 `R` 从头播放。
2. 录屏软件选 1920×1080、60fps，窗口最大化后画面会自动缩放到铺满。
3. 想重录某一幕：在地址栏加 `?t=28`（秒）直接跳到那一幕起点，再按空格开始播。

| 时间 | 幕 | 画面 |
|---|---|---|
| 0–6.5s | 一 | 一堆 KO 丰度表格，数字在跳动 |
| 6.5–15s | 二 | 第一个 KO（K02035）放大，LA1 / LB1 / LC1 三个值与它的功能类 |
| 15–28s | 三 | 48 个 KO 逐个立到圆周上，三行丰度色块依次上色 |
| 28–40s | 四 | 右侧长出 17 个功能类：蓝=Metabolism、粉=Other，柱子和弦同时生成 |
| 40–52s | 五 | 图淡出，只剩两个主题数字：相对丰度 0.17–0.69%、连接度 1–16 |
| 52–68s | 六 | 图从中间长回来：KO 编号、功能类名、图例依次出现 |
| 68–84s | 七 | 收拢并**淡入真正的 output/figure.png**，标题打字机，三组小字讲解 |

最后一幕落的就是 `output/figure.png` 本身：手绘部分与它的圆心、半径按像素对齐
（圆心在图的 48.17% / 55.62% 处，外环半径 = 图宽的 28.00%），所以淡入时没有重影。

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 暂停 / 继续 |
| `R` | 从头重播 |
| `←` `→` | 后退 / 前进 1 秒 |
| `H` | 隐藏 / 显示控制条 |

URL 参数：`?t=37`（跳到第 37 秒并暂停）、`?hud=0`（隐藏控制条）。

## 数据

画面里所有数字都来自仓库的 `data/processed/`：48 个 KO、92 条 KO–功能类关系、17 个功能类、
相对丰度 0.17%–0.69%、连接度 1–16。改数据后重新生成：

```bash
python3 video/build_scene.py     # 读 data/processed → 写出 video/scene.html
```

`scene.template.html` 是模板，`scene.html` 是生成物（数据已内联）。要调时长，改模板里的 `T` 常量；
要调配色，改 `COL` / `CMAP`。
