# v1 — 视觉重做前的第一版

这是 ScienceGuru 在**原始简单指令**下直接做出来的图：需求只有一张参考截图和一句「照这个样子做」。
它已经是完整可复现的产物（同一份数据、48 个 KO、129 项校验），但版式上存在几个问题：

- 功能类标签用 8.2pt 粗体、双层交错，在窄扇区里靠错位避免压字
- 功能类轨道填充是 `#FBE8ED` 淡粉，白底上对比度只有 1.17:1，几乎看不出形状
- 样本图例横排铺满底部，和色标、连接度标尺挤在同一行
- 画布是正方形，位置靠手工调坐标

这些都在第二版里逐条改掉了，过程见仓库根目录 README 的「两轮：原始指令 vs 对话微调」。

## 复现

```bash
python3 archive/v1/02_plot_circos_v1.py     # 输出 archive/v1/figure.png
```

脚本与第二版只差两处路径：`ROOT` 指到仓库根（本文件在 `archive/v1/` 下），`OUT` 指向本目录，
避免覆盖 `output/`。其余渲染逻辑与第一版完全一致，图像逐字节可复现（sha256 `0a0de4c3d1308ed5…`）。

数据依赖与主流程相同，来自 `data/processed/`；如尚未生成，先在仓库根执行 `bash run.sh`。
